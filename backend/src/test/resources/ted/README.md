# TED test fixtures

`sample-2026-11-06.json` contains real notices published in TED on 2026-11-06, retrieved from the TED Search API v3
(https://api.ted.europa.eu) and trimmed to the fields the application requests. Source: © European Union, TED – Tenders
Electronic Daily. Each entry is keyed by the case it exercises (single-lot competition, multi-lot, change, cancellation,
award with aligned/misaligned winner lists, award without winner, contract modification, VEAT, prior information,
non-EU buyer, notice without procedure identifier, non-ISO-tabled currency, UTC deadline).

They are used only as parser and ingestion test input.
